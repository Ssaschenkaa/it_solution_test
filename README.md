# Веб-сервис для управления движением денежных средств (ДДС)

## Описание

Веб-приложение для учета, управления и анализа поступлений и списаний денежных средств (ДДС). Пользователи могут создавать, редактировать, удалять и просматривать записи о движении денежных средств с учетом различных параметров, таких как дата, статус, тип, категория, подкатегория, сумма и комментарий.

Данный проект разработан Александром Ивановым — студентом-бэкенд разработчиком — в рамках тестового задания для компании **IT-Solutions**. Проект реализован с использованием фреймворка Django и Django REST Framework с адаптированным пользовательским интерфейсом на HTML и Bootstrap.

## Возможности приложения

- **Создание записи о ДДС**:
  - Дата создания записи (можно изменить вручную).
  - Статус: Бизнес, Личное, Налог (можно расширять).
  - Тип: Пополнение, Списание (можно расширять).
  - Категория и подкатегория (например, Инфраструктура — VPS, Proxy; Маркетинг — Farpost, Avito).
  - Сумма (в рублях).
  - Комментарий (необязательное поле).
- **Просмотр записей**:
  - Таблица с фильтрацией по дате, статусу, типу, категории и подкатегории.
- **Редактирование записи**:
  - Возможность изменения существующей записи.
- **Удаление записи**:

  - Возможность удаления существующей записи.

- **Управление справочниками**:
  - Добавление, редактирование и удаление статусов, типов, категорий и подкатегорий.
  - Логические зависимости между сущностями (например, подкатегория привязана к категории).

## Установка и запуск проекта

1. Клонировать репозиторий:

   ```
   git clone https://github.com/ваш-репозиторий.git
   cd ваш-репозиторий

   ```

2. Создать и активировать виртуальное окружение:

   ```
   python3 -m venv venv
   source venv/bin/activate # Windows: venv\Scripts\activate

   ```

3. Установить зависимости:

   ```
   pip install -r requirements.txt

   ```

4. Применить миграции:

   ```
   python manage.py migrate

   ```

5. Создать суперпользователя (по желанию):

   ```
   python manage.py createsuperuser

   ```

6. Запустить сервер разработки:

   ```
   python manage.py runserver

   ```

7. Перейти в браузере по адресу http://127.0.0.1:8000

## Структура проекта

- cashflows/ — модель для учета движений денежных средств.
- categories/ — модель для категорий (например, Инфраструктура, Маркетинг).
- subcategories/ — модель для подкатегорий (например, VPS, Farpost).
- types/ — модель для типов операций (Пополнение, Списание).
- statuses/ — модель для статусов (Бизнес, Личное, Налог).
- users/ — модель пользователей.

## Бизнес-правила

- Подкатегории жёстко связаны с категориями.
- Категории привязаны к определённым типам операций.
- Нельзя выбрать подкатегорию без выбора соответствующей категории.
- Нельзя выбрать категорию, не связанную с указанным типом.

# CashFlow API

API для управления движением денежных средств (ДДС).

---

## 🔐 Аутентификация

### `POST /auth/token/login/`

Авторизация пользователя по email и паролю.

**Тело запроса:**

```json
{
  "email": "user@example.com",
  "password": "your_password"
}
```

**Ответ:**

```json
{
  "auth_token": "your_token"
}
```

---

### `POST /auth/token/logout/`

Выход пользователя.

**Заголовок:**

```
Authorization: Token your_token
```

---

## 👤 Пользователи

### `GET /users/`

Получить список пользователей.

### `POST /users/`

Создать нового пользователя.

**Тело запроса:**

```json
{
  "username": "ivan123",
  "email": "ivan@example.com",
  "first_name": "Иван",
  "last_name": "Иванов",
  "password": "secret"
}
```

---

## 💸 Записи ДДС (CashFlow)

### `GET /cashflows/`

Получить список всех записей.

**Поддержка фильтрации через query-параметры:**

| Параметр            | Описание                    |
| ------------------- | --------------------------- |
| `pub_date__gte`     | Начальная дата (YYYY-MM-DD) |
| `pub_date__lte`     | Конечная дата (YYYY-MM-DD)  |
| `status__slug`      | Слаг статуса                |
| `type__slug`        | Слаг типа                   |
| `category__slug`    | Слаг категории              |
| `subcategory__slug` | Слаг подкатегории           |

---

### `POST /cashflows/`

Создать новую запись.

**Заголовок:**

```
Authorization: Token your_token
```

**Тело запроса:**

```json
{
  "status": "biznes",
  "type": "popolnenie",
  "category": "infrastruktura",
  "subcategory": "vps",
  "amount": "1000.00",
  "comment": "оплата VPS"
}
```

---

### `PATCH /cashflows/{id}/`

Частично обновить запись по ID.

---

### `DELETE /cashflows/{id}/`

Удалить запись по ID.

---

## 📘 Справочники

### Типы

- `GET /types/` — список всех типов (например, "пополнение", "списание")
- `POST /types/` — добавить новый тип

**Пример тела запроса:**

```json
{
  "name": "Возврат",
  "slug": "vozvrat"
}
```

---

### Статусы

- `GET /statuses/` — список всех статусов (например, "личное", "бизнес")
- `POST /statuses/` — добавить новый статус

**Пример тела запроса:**

```json
{
  "name": "Подарок",
  "slug": "podarok"
}
```

---

### Категории

- `GET /categories/` — список всех категорий
- `POST /categories/` — добавить новую категорию

**Пример тела запроса:**

```json
{
  "name": "Транспорт",
  "slug": "transport",
  "type": 2
}
```

---

### Подкатегории

- `GET /subcategories/` — список всех подкатегорий
- `POST /subcategories/` — добавить новую подкатегорию

**Пример тела запроса:**

```json
{
  "name": "Такси",
  "slug": "taksi",
  "category": 5
}
```

---

```http
GET /cashflows/?type__slug=spisanie&category__slug=marketing&pub_date__gte=2025-01-01&pub_date__lte=2025-01-31

```
